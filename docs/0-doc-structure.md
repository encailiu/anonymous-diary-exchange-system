# 匿名日記ランダム交換システム ドキュメント構成

本システムに関するドキュメント群の構成および各ファイルの役割は以下の通りです。

1. **`1-basic-spec-v1.0.md` (基本仕様書)**
   - システムの目的、背景、ターゲットユーザー、利用シーン、サービスコンセプト、運営方針を定義。
2. **`2-require-spec-v1.0.md` (要求仕様書)**
   - 投稿、締切、マッチング、匿名性、写真、コメント、メール、データ保存/アーカイブ、エラー処理などの詳細要件を定義。
3. **`3-basic-design-v1.0.md` (基本設計書)**
   - システム構成図、コンポーネント設計、スプレッドシートデータモデル、セキュリティ＆プライバシー設計を定義。
4. **`4-impl-spec-v1.0.md` (実装仕様書)**
   - GASモジュール分割、アーカイブ・データ削除処理、複数管理者通知、メール抽象化モジュール等の具象実装仕様を定義。
5. **`5-agent-dev-inst.md` (AIエージェント開発指示書)**
   - AIエージェントおよび開発者が実装を進めるためのフェーズ計画、優先ルール、必須テストケース等を定義。
