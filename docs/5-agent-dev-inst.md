# AIエージェント 開発指示書 v1.0

## 0. 開発における優先ルール
1. **完全匿名性の徹底保障**
2. **誤配信・二重送信の徹底防止**
3. **運用・保守コストゼロ（追加課金が発生する構成は不可）**
4. **複数管理者へのエラー通知**
5. **データアーカイブ・削除によるメンテナンス性の担保**

---

## 1. 実装フェーズ計画

### Phase 0：調査
- コード非破壊でのリポジトリ調査・構造確認。

### Phase 1：基盤・設定
- Sheets構成、複数管理者アドレス設定 (`ADMIN_EMAILS`) の読み込み。
- 拡張可能なメール送信モジュール (`mail.gs`) とエラーハンドラ (`errors.gs`) の作成。

### Phase 2：日次交換バッチ
- 締切判定 (JST 22:00)、当日投稿抽出、ランダムマッチング、Gmail送信、二重送信防止、エラー発生時の複数管理者アラート通知。

### Phase 3：マッチング改善
- 直近7日間履歴回避、奇数人数のスキップ救済ロジック。

### Phase 4：匿名コメント機能
- `comment_token` 発行、Web App画面構築、匿名コメント通知。

### Phase 5：運用・メンテナンス機能
- カスタムメニュー追加、手動実行・再送機能。
- 日付指定によるデータアーカイブ（CSV Drive保存）および旧データ物理削除機能の実装。
- `README.md` および `SETUP.md` の作成。

### Phase 6：セキュリティ・匿名性最終レビュー
- 匿名性漏洩チェック、権限検証、複数管理者宛通知テスト。

---

## 2. 必須テストケースの追加要件
- **複数管理者通知**: システム例外発生時に、指定されたすべての管理者アドレス宛にアラートメールが届くこと。
- **データアーカイブ・削除**: 指定日付以前のデータのみがCSVとして正しくDriveに出力され、スプレッドシートから安全に消去されること。指定日以降のデータが消えないこと。
- **メール拡張性**: `mail.gs` を通じた抽象化送信が正しく動作すること。
