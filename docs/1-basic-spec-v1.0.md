# 匿名日記ランダム交換システム 基本仕様書 v1.0

## 1. 目的
20～30人程度の固定参加者（学生団体等）が毎日匿名で日記を投稿・交換し、お互いの個人情報を隠したまま安全にコミュニケーションおよびコメント交流を行える環境を提供する。

## 2. 背景
小規模なコミュニティや学生団体において日常的な交流を促進したいニーズがある一方、既存のSNSや連絡先交換では個人情報の開示に伴う心理的ハードルが存在する。完全匿名性を担保したランダム交換システムを構築することで、心理的安全性を保ちつつ団体内の相互理解と親睦を深める。

## 3. ユーザー
- **主対象**: 学生団体などの固定メンバー（20～30人程度、将来拡張で最大50人程度）
- **運用形態**: 招待・登録済みの固定メンバー制（外部ユーザーの自由参加は不可）
- **管理者**: 学生団体の運営担当者（非ITエンジニアでも運用可能なシンプルな構造）

## 4. 利用シーン
- 参加者が日常の出来事や思考を投稿（締切：毎日22:00）。
- 夜間（22:05頃）に相手の日記がメールで届き、匿名のまま読書・感想共有を行う。
- 日記末尾の専用リンクから気兼ねなく匿名コメントを送信し、お互いのリアクションを楽しむ。

## 5. サービスコンセプト
**「顔も名前も知らない仲間と、日常をそっと共有する匿名日記交換」**
- **学生団体の交流を安全に深める**: 完全匿名性を徹底し、個人情報を防護した安心感の中でメンバー同士の心の距離を縮める。
- **運用・保守コストゼロ**: サーバーレスおよび既存のGoogleエコシステム（Google Forms, Sheets, GAS, Gmail）の活用により、初期導入費用・月額運用費用を一切かけずに運用する。

## 6. 運営方針
1. **完全匿名性の最優先**: システム内部で紐付け管理を行いつつ、参加者間ではメールアドレス・氏名等の漏洩を絶対に発生させない。
2. **ノーコスト＆ローノイズ**: 有料インフラや外部APIに依存せず、完全無料で永続運用可能な設計を貫く。
3. **安全配慮と復旧性**: 日記本文へ個人情報を記載しないよう注意喚起を行うとともに、万が一のエラー時には複数管理者への自動通知および手動再実行手段を用意する。
